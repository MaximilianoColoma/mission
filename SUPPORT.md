# Support

This open-source project is maintained on a best effort basis.

- Use GitHub issues for reproducible defects and bounded feature proposals.
- Use discussions or an issue before large design work.
- Follow `SECURITY.md` for vulnerabilities; do not disclose them publicly first.
- Include versions, operating system, installation method, minimal reproduction, expected behavior, actual behavior, and redacted logs.

There is no guaranteed response time, uptime, migration service, or production support commitment. A public repository, accepted pull request, release, or green CI run does not claim that the software is deployed or suitable for a particular production environment.
